# React To-Do List
A simple To-Do List application built using React and Vite.

## Features
- Add tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks

## Technologies
- React
- JavaScript
- Vite
- CSS

## Github
https://github.com/patelparth2183/To-Do-list-react

## How to Run
1. Clone the repository.
2. Open the project folder.
3. Install dependencies:
    npm install
4. Start the development server:
    npm run dev
5. Open the localhost URL in your browser.
